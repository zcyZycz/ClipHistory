# 剪切板历史 ClipHistory

一个轻量的 Windows 剪贴板历史工具：自动记录复制过的**文字**和**图片**，默认保留 3 天，常驻系统托盘。

单文件、免安装、无需 .NET 运行库（Win10/11 自带）。

---

## 快速开始

双击 `ClipHistory.exe` 即可运行。

- 主窗口打开，「文字」「图片」两个标签页
- 复制任何内容，会自动出现在对应标签页
- 关闭窗口 `X` → 缩到系统托盘（程序继续运行）
- 点最小化 `—` → 留在任务栏
- 托盘图标**单击** → 打开主界面
- 托盘图标**右键** → 打开 / 清空 / 退出
- 全局热键 **Ctrl + Alt + V** → 任何地方都能叫出窗口

> 找不到托盘图标？按 Ctrl+Alt+V，或再双击一次 exe。

## 功能

### 自动记录

| 内容 | 说明 |
|---|---|
| 文字 | 最多保留 1000 条，单条上限 20 万字符 |
| 图片 | 最多保留 200 张，自动存成 PNG |

复制相同内容不会重复记录（与最新一条比较）。

### 保留期限

默认 **3 天**，可在工具栏改成 1–365 天。

清理时机：

- 程序启动时
- 运行中每 5 分钟
- 修改保留天数时立即生效

**注意**：程序关闭期间不清理，下次启动会补删过期项。

**删除是永久删除，不进回收站。**

### 文字页操作

| 操作 | 效果 |
|---|---|
| 单击 | 选中（浅蓝色高亮） |
| 双击 | 复制该条到剪贴板 |
| `Ctrl + C` | 复制选中项 |
| `Ctrl + A` | 全选 |
| `Delete` | 删除选中（有确认框） |
| 右键 | 复制 / 删除 / 全选 |
| 按住左键拖动 | 框选多个（半透明蓝框），划过的条目被选中 |
| `Ctrl` / `Shift` + 拖动 | 追加选择 |

### 图片页操作

| 操作 | 效果 |
|---|---|
| 单击 | 选中 |
| **双击** | **用系统看图程序打开原图**（可放大查看） |
| `Ctrl + C` | 复制图片到剪贴板 |
| 右键 | 复制图片 / 删除 / 全选 |
| 拖动 | 框选多个 |

缩略图为 160×160，显示尺寸 128px。

### 工具栏

| 按钮 | 作用 |
|---|---|
| 复制选中 | 复制当前选中项（也可双击/ Ctrl+C） |
| 删除选中 | 删除选中项（弹确认框，支持多选） |
| 清空全部 | 清空所有历史（弹确认框） |
| 数据目录 | 用资源管理器打开数据文件夹 |
| 使用说明 | 显示本说明（内嵌在 exe 中） |
| 保留天数 | 1–365 天，修改立即生效 |
| 开机自启 | 勾选后写入注册表，开机静默运行 |

## 开机自启

勾选「开机自启」后写入：

```
HKEY_CURRENT_USER\Software\Microsoft\Windows\CurrentVersion\Run
    DSHClip = "<程序完整路径>" --tray
```

带 `--tray` 参数启动时：

- **不显示主窗口**
- **不弹托盘气泡**
- 只在托盘放一个图标，后台正常记录剪贴板

取消勾选会自动删除该注册表项。

## 数据存放（便携模式）

所有程序产生的文件都在 **exe 旁边的 `data` 文件夹**：

```
ClipHistory\
├── ClipHistory.exe
└── data\
    ├── texts.dat        文字记录（Base64 编码）
    ├── images.dat       图片索引（时间 / 文件名 / 宽高）
    ├── settings.ini     设置（保留天数）
    ├── img\             图片文件（PNG）
    └── logs\
        ├── start.log    启动日志
        └── crash.log    崩溃日志（仅在崩溃时生成）
```

- **换电脑 / 换盘**：整个文件夹复制过去，历史全带走
- **备份**：复制 `data` 文件夹
- **清空**：界面点「清空全部」，或直接删 `data`

只有开机自启需要写注册表（Windows 只认这个），其余全部在本地文件里。

若 exe 所在目录不可写（如放在 Program Files），会自动降级到
`%LOCALAPPDATA%\DSHClip`，日志里会写明使用哪个目录。

## 命令行参数

| 参数 | 作用 |
|---|---|
| 无 | 正常启动，显示主界面 |
| `--tray` | 启动后直接隐藏到托盘（开机自启使用） |
| `--selftest` | 存储读写自检，结果写入 `data\logs` 附近 |
| `--uitest` | 窗体构造自检 |
| `--shot` | 渲染界面截图 `ui-shot.png`（开发调试用） |

## 已知限制

| 限制 | 说明 |
|---|---|
| 只记录文字和图片 | 复制的**文件**（资源管理器 Ctrl+C 文件）不会被记录 |
| 单条文字上限 | 20 万字符，超出截断 |
| 1000 条 / 200 张 | 超出后按时间淘汰最旧的 |
| 明文存储 | 密码、验证码复制后会留 3 天，用完请「清空全部」 |
| 永久删除 | 删除不进回收站，不可恢复 |
| 无数字签名 | 首次运行可能被 SmartScreen 或杀软提示，选择「仍要运行」并加白名单 |

建议：把程序放在桌面、D 盘、U 盘等可写位置，避免目录不可写触发降级。

## 常见问题

**Q：双击图片没反应？**
A：状态栏会显示原因。若提示「图片文件不存在」，说明 `data\img` 里的文件被删了。

**Q：开机后托盘没有图标？**
A：检查注册表 `HKCU\...\Run` 是否有 `DSHClip`；或看 `data\logs\start.log` 有没有开机时间的记录。

**Q：记录突然少了？**
A：超过保留天数的会被自动清理；也可能是切到了另一个数据目录（看日志里的「数据目录」）。

**Q：能记录复制过的文件吗？**
A：目前不支持，只记录文字和图片。

**Q：怎么彻底卸载？**
A：删除整个文件夹，再到注册表删掉 `HKCU\...\Run\DSHClip`（如果开过自启）。
